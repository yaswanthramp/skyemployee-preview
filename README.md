# skyEmployee preview

Clickable UX wireframe for skyEmployee, an employee experience app: Home with a welcome banner, My Apps, app widgets and a community feed, plus Directory and Who's On Today, Rewards (gift cards and e-cards), Resources & Policies, and the Controller and Admin areas.

- Use **View as** in the header to switch between Employee (Frontline), Employee (Office), Controller and Admin.
- Use the phone icon to preview the mobile layout.
- All people, locations and brands are sample data.

Built with the Skypoint Radix design system.
